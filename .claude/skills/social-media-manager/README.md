# Social Media Manager Skill 📱

A Claude skill that acts as an elite social media strategist with deep expertise in viral content creation, platform algorithms, AI-driven content generation, and conversion-focused social marketing.

## What This Skill Does

The Social Media Manager helps you:
- **Create Viral Content**: Design posts, hooks, and campaigns engineered for maximum reach
- **Generate AI Content**: Create detailed prompts for AI-generated images, videos, and copy
- **Optimize by Platform**: Tailor content for each platform's algorithm and audience
- **Grow Organically**: Apply proven growth hacking tactics
- **Drive Conversions**: Turn social media attention into website visits and customers
- **Leverage Trends**: Identify and capitalize on trending topics and formats
- **Analyze Performance**: Make data-backed content decisions

## When to Use This Skill

Use the Social Media Manager when you need to:
- Launch a product on social media
- Create a content strategy for a platform
- Write hooks that stop the scroll
- Generate AI prompts for social media visuals
- Optimize posts for specific algorithms (Twitter, LinkedIn, Instagram, TikTok)
- Grow followers and engagement organically
- Turn social media followers into customers
- Create viral content campaigns
- Plan content calendars
- Analyze what's working and what's not

## Platform Expertise

This skill has deep knowledge of:
- **Twitter/X**: Thread tactics, hook writing, algorithm optimization
- **LinkedIn**: Professional storytelling, thought leadership, B2B content
- **Instagram**: Reels, carousels, Stories, aesthetic consistency
- **TikTok**: Viral video formulas, trending sounds, watch time optimization
- **YouTube**: Shorts and long-form content, thumbnails, titles
- **Facebook**: Native video, group strategies
- **Reddit**: Community building, authentic value-add
